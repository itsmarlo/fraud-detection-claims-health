# SAP Fioneer brand assets

The prototype UI uses the public SAP Fioneer web identity current on 2026-07-21:

- `sap-fioneer-logo.svg` from `https://www.sapfioneer.com/wp-content/uploads/2025/10/logo-sap-fioneer-yellow.svg`
