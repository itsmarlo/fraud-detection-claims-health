# WanderPlan

A small local travel planner written in Python. It lets you explore destinations, estimate a trip budget, and save itineraries locally in a clean browser interface.

## Run the app

Python 3.10 or newer is recommended.

```bash
python3 travel_app.py
```

No extra packages are required. Your browser opens automatically, and saved trips are written to `trips.json` beside the app. Press **Ctrl+C** in the terminal to stop the app.
